# Your Agent in One Emoji

One glyph that stands for the agent: 🧠 — the entry writes it to `/output/entry.txt`
and the bounty judge compares it pairwise against the field. Picked against the judge's
published criteria: it reads instantly at small size, says something specific about how
the agent works, and stays far from the obvious robot or smiley half the field sends.

## Run it

```sh
python3 main.py
```
